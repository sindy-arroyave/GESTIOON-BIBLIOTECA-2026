# Guía de entrega

Entregue el archivo `SistemaGestionBiblioteca-Entrega.zip`. Dentro se encuentran los cuatro elementos solicitados:

1. Documento: `docs/INFORME.md` y su versión de lectura `docs/INFORME.pdf`.
2. Código fuente: `SistemaGestionBiblioteca.sln` y la carpeta `src`.
3. Script SQL: `sql/01_Crear_BibliotecaDB.sql`.
4. Repositorio Git: todo el contenido, incluido `README.md`, `docs/capturas` y `docs/EVIDENCIA_GIT.md`.

Antes de presentar en el computador del evaluador:

1. Ejecute `sql/01_Crear_BibliotecaDB.sql` en SQL Server.
2. Revise la cadena `BibliotecaDb` en `src/Biblioteca.Presentacion/App.config`.
3. Abra `SistemaGestionBiblioteca.sln`, compile e inicie `Biblioteca.Presentacion`.
4. Publique el repositorio en su cuenta de GitHub y entregue también el enlace, porque esa acción requiere sus credenciales personales.
